# 高性价比系列 · 官网单页

科技青暗色主题、响应式单页官网，展示系列微信小程序（二维码 + 介绍 + 一键跳转）。

## 目录结构

```
website/
├── index.html          # 官网单页（所有样式/脚本内联，可直接部署）
└── assets/
    ├── qr-life.png     # 「高性价比人生指南攻略」二维码（当前为占位图，待替换）
```

## 待替换的两件事（上线前必做）

### 1. 替换真实小程序码

当前二维码为占位图（扫不出小程序）。请到
**微信公众平台（mp.weixin.qq.com）→ 小程序后台 → 设置 → 基本设置 → 小程序码及线下物料下载**
下载官方小程序码，覆盖 `assets/qr-life.jpg` （保持文件名不变即可，无需改代码）。

### 2. 配置手机端「点击跳转」链接

在 `index.html` 底部的 `APPS` 配置中，把对应小程序的 `scheme` 字段从 `""` 改为微信生成的跳转链接：

- 方式一：微信公众平台 → 设置 → 需开启「URL Scheme/URL Link」后由服务端接口生成（`https://wxaurl.cn/xxxx`）
- 方式二：微信 PC 端打开小程序 → 复制链接，得到 `#小程序://名称/xxx` 复制链接（部分场景可用）

配置后，手机浏览器中点击二维码或「在微信中打开」按钮，会直接唤起微信进入小程序；
留空时点击则放大展示二维码，引导扫一扫。

## 新增第 2 个小程序

打开 `index.html`，在 `APPS` 数组中追加一个对象即可（导航、卡片自动生成）：

```js
{
  id: "xxx",
  name: "小程序名称",
  tag: "分类标签",
  icon: "🧩",
  grad: "g-orange",          // 可选 g-teal / g-blue / g-orange
  tagline: "一句话卖点",
  desc: "2~3 句介绍",
  feats: ["特性1", "特性2"],
  qr: "assets/qr-xxx.png",
  scheme: ""
}
```

## 部署

纯静态页面，任意静态托管即可（如「发布为应用」一键上线，或 Vercel / Cloudflare Pages / 任意虚拟主机），把 `website/` 整个目录上传即可。
